Java HTTP Server Line-by-Line Guide

Java Web Concepts Without Heavy Frameworks or XML Files

1. Concept Mapping: Standard Java HTTP vs Jakarta Servlets

How built-in JDK server components map directly to Jakarta/Javax Servlet concepts taught in enterprise Java:

Built-in JDK Class Jakarta Servlet Equivalent Purpose & Definition
HttpServer Tomcat / Jetty Server Listens on a TCP port (e.g., 8080) and routes incoming connections.
HttpHandler HttpServlet Interface that handles incoming requests and generates responses.
HttpExchange HttpServletRequest + HttpServletResponse Encapsulates BOTH the request (headers/body) and response stream in one object.
exchange.getRequestBody() request.getInputStream() Byte stream for reading incoming POST/PUT payloads.
exchange.getResponseBody() response.getOutputStream() Byte stream for sending data back to the client/browser.

3. Imports & Core Classes

Definitions of key JDK APIs used in the code:

  • HttpServer
    The underlying HTTP engine provided by Oracle/OpenJDK. Listens for incoming socket connections and dispatches them to contexts.
  • HttpExchange
    Represents a single HTTP transaction. Used to read request headers/body and send response headers/body back to the client.
  • InetSocketAddress(8080)
    Pairs an IP address (or 0.0.0.0) with a TCP port number to establish a listening socket.

4. Data Safety & Multi-Threading

Why thread-safe objects are crucial in web servers:

  • ConcurrentHashMap<K,V>
    Standard HashMap fails under concurrent web requests. ConcurrentHashMap uses segment-level locks to allow safe parallel reads and writes without crashing the server.
  • AtomicInteger
    A thread-safe counter. incrementAndGet() ensures that even if two POST requests arrive at the exact same millisecond, each gets a unique auto-incremented ID.

5. Stream I/O Operations

How HTTP data travels through network streams:

  • exchange.getRequestBody()
    Returns an InputStream. We read raw bytes sent by client payloads (like POST or PUT JSON bodies).
  • sendResponseHeaders(statusCode, length)
    Sends HTTP status line (e.g., 200 OK, 404 Not Found) and total content length in bytes before writing the body.
  • exchange.getResponseBody()
    Returns an OutputStream. We convert text into UTF-8 byte arrays and write them back over the socket.
